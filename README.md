# Immune-System

Repositório oficial do Sistema Imunológico.

Este repositório mantém o núcleo soberano próprio e utiliza componentes externos exclusivamente como **doadores Open Source**, de forma limpa, auditável, substituível e sem vínculo de histórico Git com os repositórios de origem.

## Regra fundamental de doadores

Antes de construir qualquer módulo, o projeto deve procurar uma peça Open Source madura que possa ser reutilizada. Nenhum doador substitui o núcleo, o Supervisor, o IMUNE-DNA ou o critério MISSION_PROVEN.

A entrada de doadores é controlada por `donors/registry.yaml` e pela política em `donors/DONOR_INTAKE_POLICY.md`.
